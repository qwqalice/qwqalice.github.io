## About Me

I am a Master's student at the School of Computer Science and Technology, East China Normal University (ECNU), and a member of the Visual Perception + X (VPX) Group. My research interests include video content understanding, temporal modeling, multimodal large models, and robust visual recognition.

## Site Features

- **Homepage** — Bio, education, experience, projects, awards, and news
- **Publications** — List of publications with links to papers
- Built with [Jekyll](https://jekyllrb.com/) and the [academic-homepage](https://github.com/luost26/academic-homepage) template

## Running Locally

```bash
bundle exec jekyll serve
```
